# Aigis_ver2

キャチロボバトルコンテスト2025のdefendersチームの機体(Aigis)のコード整理用リポジトリ  
<Mainsサークル紹介(2026/04/08)にて操作体験用に書き直したもの>

## 操縦方法

1. RemoteXYアプリを入れたAndroidスマホを用意する(課金は必要ない) ←金栄の私物があるのでそれ使う？
2. スマホのBluetoothをONにした状態でRemoteXYアプリを開き、左上の「三」→「New dwvice」→「Bluetooth classic」で「Aigis_ver2」を選択、操作画面を開く
3. 左のボタンを押してONにして、ESP32が青く光るのを確認する
4. 真ん中のオレンジの〇を上下左右に動かすとアームが前後左右に動く
5. 右のオレンジの〇を上下させるとアームが上下する
6. 左のオレンジの〇を左に動かすとハンドが閉じ、右に動かすと開く
7. 左のボタンを再度押してOFFにしてから接続を切ると暴走する心配がない

## 接続

- X(左右),Y(前後),Z(上下)軸のモーターをモータードライバーにつなぎ、信号線をESP32につなぐ
  信号線はそれぞれ14,27(X), 26,25(Y), 33,32(Z)を使用する。モーターの回転方向と操縦UIとで向きが逆なら黄色と緑の信号線を逆につなげる。
- ハンド部のサーボの線は、操縦者から見て左に黄色のマスキングテープが貼ってあるので、そっちを21ピンにつなげ、もう片方は18ピンにつなげる。
  こちらも実際動かしてみて逆だった場合は逆につなげる。
